MICROSOFT VISUAL C++ APPLICATION-LOCAL RUNTIME
==============================================

These signed x64 runtime DLLs are copied beside the llama.cpp executables so
the portable chat can run on Windows computers that do not already have the
Visual C++ Redistributable installed. They do not install into Windows or
change the registry.

Version: 14.44.35211.0
Source: Microsoft Visual Studio 2022 Build Tools redistributable files
Deployment guidance:
https://learn.microsoft.com/cpp/windows/choosing-a-deployment-method
Redistribution terms:
https://learn.microsoft.com/cpp/windows/redistributing-visual-cpp-files
