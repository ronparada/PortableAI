MACOS - SIMPLE START
====================

FIRST TIME ON THIS USB
1. Open Terminal.
2. Type bash followed by a space.
3. Drag 1-SETUP-PORTABLE-CHAT.sh into Terminal and press Return.
4. Choose 1 for the recommended Qwen setup.
5. Run file 2 the same way to start Qwen Chat.

File 3 starts the alternate Nous Hermes 3 language model. File 4 stops a chat
left running after its Terminal window closed. Keep Terminal open while using
the chat.

Setup and both chat launchers keep their files on the USB.
