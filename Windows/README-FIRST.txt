WINDOWS - SIMPLE START
======================

FIRST TIME ON THIS USB
1. Double-click 1-SETUP-PORTABLE-CHAT.cmd.
2. Choose 1 for the recommended Qwen setup.
3. When it finishes, double-click 2-START-QWEN-CHAT.cmd.

OTHER FILES
- 3-START-NOUS-HERMES-3-MODEL.cmd starts the alternate Nous Hermes 3 model.
- 4-STOP-PORTABLE-AI.cmd stops a chat left running after its window closed.
- 5-START-LAB-ASSISTANT.cmd opens an optional local file assistant. Choose a lab
  folder when prompted. It can find hidden files, read small text files, and
  preview sorting screenshots by month. Type /apply and then MOVE to carry out
  a previewed sort.

Keep the black terminal window open while chatting. Closing it normally stops
the local server. Setup and both chat launchers keep their files on the USB.
