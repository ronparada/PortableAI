LINUX - SIMPLE START
====================

FIRST TIME ON THIS USB
1. Open a terminal in this Linux folder.
2. Run: bash 1-SETUP-PORTABLE-CHAT.sh
3. Choose 1 for the recommended Qwen setup.
4. Run: bash 2-START-QWEN-CHAT.sh

File 3 starts the alternate Nous Hermes 3 language model. File 4 stops a chat
left running after its terminal closed. Keep the terminal open while chatting.

Setup and both chat launchers keep their files on the USB.
