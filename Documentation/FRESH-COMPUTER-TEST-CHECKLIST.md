# Fresh-computer test checklist

Use this checklist on Windows, Apple Silicon macOS, and a current Ubuntu-compatible Linux computer.

## Portable student workflow

1. Copy or extract a clean source package to the USB.
2. Run file 1 while online and choose option 1.
3. Disconnect from the internet.
4. Run file 2 and ask: `Reply with exactly QWEN_OK`.
5. If option 2 was selected during setup, run file 3 and ask: `Reply with exactly MODEL_OK`.
6. Close the browser and stop from the terminal. Run file 4 and confirm port 18765 is free.
7. Record any antivirus product, filename, detection name, and whether the file was blocked. Do not disable protection to pass the test.
