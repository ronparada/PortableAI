# PortableAI

PortableAI is an offline chat tool for a USB drive. It runs a local
Qwen 3 or Nous Hermes 3 language model in a browser using `llama.cpp`; setup
downloads the selected model and the appropriate runtime to the USB drive.

Start with [START-HERE.txt](START-HERE.txt). The numbered launchers in the
Windows, macOS, and Linux folders provide setup, model launch, and shutdown.

The project intentionally excludes model files and runtime downloads. Run setup
once while online from the USB drive; afterward the selected chat model works
offline on a compatible computer.

See [Documentation/QUICK-START.txt](Documentation/QUICK-START.txt) for use
instructions, [Documentation/THUMBDRIVE-INTEGRATION.txt](Documentation/THUMBDRIVE-INTEGRATION.txt)
for placement on a multiboot drive, and
[Documentation/TECHNICAL-README.md](Documentation/TECHNICAL-README.md) for
supported platforms, downloads, and verification details.
