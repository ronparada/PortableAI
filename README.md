# PortableAI Classroom Kit

PortableAI is a student-ready offline chat kit for a USB drive. It runs a local
Qwen 3 or Nous Hermes 3 language model in a browser using `llama.cpp`; setup
downloads the selected model and the appropriate runtime to the USB drive.

Start with [START-HERE.txt](START-HERE.txt). The numbered launchers in the
Windows, macOS, and Linux folders are the only files students need to use.

The project intentionally excludes model files and runtime downloads. Run setup
once while online from the USB drive; afterward the selected chat model works
offline on a compatible computer.

See [Documentation/STUDENT-QUICK-START.txt](Documentation/STUDENT-QUICK-START.txt)
for student instructions and [Documentation/TECHNICAL-README.md](Documentation/TECHNICAL-README.md)
for supported platforms, downloads, and verification details.
